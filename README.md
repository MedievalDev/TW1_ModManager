# TW1 Mod Manager

Mod manager for Two Worlds 1: drop a `.wd` onto the window, enable and disable mods, verified downloads, nothing is ever deleted.

**Download:** [latest release](https://github.com/MedievalDev/TW1_ModManager/releases/latest) - `TW1_Mod_Manager.exe` (Windows, no install needed).

The manager checks this page for new versions and offers the update itself.
